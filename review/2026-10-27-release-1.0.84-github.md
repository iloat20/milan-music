# Release 1.0.84 (vc 85, b85)

本包汇总 `v1.0.79` 之后**五版**（1.0.80 ~ 1.0.84），一次装机即可升到这里。
五版全部集中在两件事上：**包体从 2.55 MB 收到 2.30 MB**（1.0.80），以及
**播放页倒影的重做**（1.0.81 ~ 1.0.84，按四张真机截图逐轮修正）。

基线：AGP 9.4.1 / Kotlin 2.4.21 / Gradle 9.8.2 / compileSdk 37 / minSdk 26。
ABI 只有 `arm64-v8a`。

## 五版一览

## 值得单独说的四条

### 一 · 体积 −246,116 B（1.0.80）

只有两项，都在构建配置里，不动一行代码：

```
localeFilters += listOf("zh-rCN", "zh-rHK", "zh-rTW")
excludes += "/META-INF/**/LICENSE.txt"
```

- AndroidX 为 85 个 locale 出串，本应用只有中文界面。arsc 从 248,272 B 降到 **33,184 B**，
  dex 与其余 183 个条目逐字节不变。
- **必须是准确 qualifier**。包内只有 `zh-rCN / zh-rHK / zh-rTW` 与五个 `en-rXX`，没有裸
  `values-zh` / `values-en`：写 `"zh"`、`"en"` 也会编译通过、体积也降，但**静默匹配 0 个
  locale**，中文串全丢（含 media3 的播放/暂停/跳转 TalkBack 文案）。判定命令：
  `apkanalyzer resources configs --type string <apk>`，只应出现 default + 三个 zh 区。
- `LICENSE.txt` 命中的是 8 份逐字节相同的 Apache-2.0 文本（压缩后合计 29,244 B）。

### 二 · 封面侧不再有过渡带（1.0.81）

第 54~81 批的模糊阶梯起点在镜面线**以上** 128dp —— 设计意图是"接缝两侧由同一图层的相邻
两行画出"，代价是**封面自己的最后 128dp 被逐级糊掉**。真机截图（873×1920）量到 y 674→960
整段清晰度从 7.06 掉到 1.80。

现在的几何：封面一直清晰到镜面线，阶梯全部落在镜面线以下（镜面线处半径 0，往下 16dp 到
12dp、64dp 到 24dp、160dp 到 34dp）。

带子归零之后有个隐藏问题：倒影区下面**什么都没有**了，而 Compose 是逐层 `over` 叠的，
`n` 层各自 alpha = `w_i` 时覆盖率只有 `1 − Π(1−w_i)`（级联 alpha 有恒等式 `Π(1−a_i) = w_0`），
镜面线上直接全透明、16dp 处只补得上一半。所以改成**归一化级联**：清晰层先画（alpha 1，
整块倒影的不透明底），第 `i` 层取 `a_i = w_i / Σ_{j≤i} w_j` —— 叠完恒等于精确的加权平均
`Σ w_j·L_j`，每一行 alpha 恒为 1。`fade` 提到父层做一次 DstIn（逐层乘会把镜下压暗一截）。

### 三 · 一条黑线和一条空白带，来自同一个改动（1.0.83 / 1.0.84）

1.0.81 把叠层绘制起点从"封面上方 128dp"搬到了镜面线。叠层是 4 个离屏图层
（`graphicsLayer(Offscreen)` + 三层 `Modifier.blur(Rectangle)`），**图层边缘会掉 alpha**，
而那条边一侧是封面、一侧是倒影，缺口就成了一条横贯全宽的黑线 —— 截图实测 y 957~962
亮度 1.1~16、横向 std 2.0~3.8，中心正落在镜像对称扫描定出的镜面线 y=959。

修法是给四个图层留 **34dp 出血**（= 最大模糊半径），并且**出血区留空不画**：出血只需要把
图层边缘挪到封面里看不见的地方，那里露出来的是封面本体，本来就长这样；而"把封面上半段
再画一遍"要依赖 `Canvas.drawImage` 与 `Image`+`ContentScale` 两套取景逐像素重合，半像素
偏差就是一层淡重影。

但这次只改了一半：采样区间改成了 `[−bleed, bottom]`（557dp），**图层 Box 的高度还是
`height`（523dp，不含出血）**，而 `RampLayerContent` 的翻折轴写死在自己的 `y = bandPx`。
「图层顶边 = 镜面线」+「翻折轴 = 镜下 34dp」叠加，整块倒影被下推 34dp，镜下留出一条
**34.0dp 的空白带**（实测 std 22.1~22.5，正常倒影 60~80，宽度与 `CoverRamp` 完全相等）。

一句话：**高度有两个来源（`overlayDrawHeight()` 与字面量 `height`），改了一个没改另一个。**
现在 fade 父层与各绘制层都读 `nodeHeight`，它是唯一高度来源。

### 四 · 一条测不进单测的约定

Box 高度那条**单元测试抓不到** —— 测试拿不到 Compose 布局，它是"两个数字必须相等却分头
写"的问题。所以 1.0.84 把防护手段改成结构性的：`nodeHeight` 只有一个来源，三处（fade 层、
各绘制层、`overlayOnly`）全部读它，注释里写清 34dp 空白带的实测数值。能测的部分（采样区间
必须同源）补了第 24 例 `the fade and the cascade share one sample range`。

## 待真机验证

1. 封面**不再有条状模糊**，正文与照片细节一直清晰到镜面线。
2. 镜面线处**无黑线、无空白带**：镜下第一行就是封面最底行的镜像，镜下 0~20dp 与镜上
   0~20dp 连续。
