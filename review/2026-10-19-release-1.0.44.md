## 本版内容

本版不含新功能，全部为质量修复。五批改动，跨度从本次全量审查（`2026-10-18-app-review.md`）到 lint 清零。

### 崩溃与功能缺陷（P0）

- **返回键不再退出应用**：播放页此前无 `BackHandler`、无关闭按钮，唯一出口是下滑手势。现在系统返回键与手势共用同一条 `dismissToHome` 路径，先滑出 240ms 再移除覆盖层（`PlayerScreen.kt`）。清单同步声明 `enableOnBackInvokedCallback`。
- **通知栏 / 锁屏 / 蓝牙封面恢复**：旧实现用 `content://media/external/audio/albumart/<id>`，该 provider 自 API 29 废弃，返回空图。新增 `ArtworkBitmapLoader` 作为 Media3 `BitmapLoader`（API 29+ 走 `loadThumbnail`，26–28 走 `embeddedPicture`），与界面侧取图路径统一。

### 性能

- **全库 filter + sort 移出主线程**：`LibraryViewModel` 的排序管线与收藏过滤加 `flowOn(Dispatchers.Default)`。
- **进度轮询改为播放态驱动**：原先 `while(isActive)` 从连接起永跑，暂停和后台各 500ms 唤醒一次。现由 `EVENT_IS_PLAYING_CHANGED` 控制，暂停即零唤醒。
- **列表封面 512px → 192px**：单张解码内存约 1.0 MB → 144 KB，24 MB LRU 覆盖专辑数 24 → 约 166。播放页封面独立保留 512px 缓存。
- **启动不再无条件建播放器**：移除 `Application.onCreate` 里 700ms 的延迟 `connect()`，改为按需连接。此前每次冷启动都创建 ExoPlayer + MediaSession。
- **服务可被正常销毁**：`MediaController` 是绑定客户端，`release()` 零调用导致 `stopSelf()` 全部失效。新增 `PlayerController.onUiStopped()`，仅在 `queueSize == 0` 时解绑，由 `MainActivity.onStop`（非配置变更）触发。

### 体验与健壮性

- 首启扫描期间显示「正在扫描音乐库」，不再闪空库文案。
- 权限被永久拒绝后提供「前往系统设置」，从设置返回自动重载曲库。
- 自适应图标新增 `monochrome` 层，支持 Android 13+ 主题图标。
- 备份规则改为 `dataExtractionRules`（按域全排除），替代弃用的 `allowBackup=false`。

### 工程卫生

- 删除约 95 行死代码（`LocalProviders.kt`、`LibrarySection.kt`、`Track.folder`、`PlayerController` 六个无调用者方法等）。
- 移除未使用依赖 `navigation-compose`、`haze-blur-materials`。
- 删除 10 个被自适应图标完全遮蔽的旧版 PNG（备份于 `backup/mipmap-legacy-icons-2026-10-19/`）。
- 依赖升级：core-ktx 1.19.1、activity-compose 1.13.0、kotlinx-serialization-json 1.11.0。
- AAB 产物首次纳入（此前仓库只有 APK，Play 不接受）。

## 尚未验证（需真机）

累计 10 项，均因当前环境无 adb 设备。按影响排序：

1. 通知栏 / 锁屏 / 蓝牙封面在 Android 12+ 的实际显示（P0 修复的有效性）
2. 播放页返回键滑出动画，含连续快速两次返回
3. 暂停后 500ms 周期唤醒是否消失
4. 未播放直接退出后 `dumpsys activity services com.milan.music` 应为空
5. 暂停返回桌面再回 App，mini player 应保留曲目
6. 首次播放的 bind 延迟（预估 100–300ms）是否可接受
7. 192px 封面在 3x 屏的观感
8. 权限往返后曲库自动加载
9. Haze 采样源方案的帧率（需 `gfxinfo` 数据，未改代码）
10. Android 8–11 小组件圆角（当前已知失效，`clipToOutline` 布局属性仅 API 31+）

## 已知遗留

- **暂停态从最近任务划掉卡片，服务仍存活**：此时有队列，绑定被主动保留以保证重开可继续。要「划掉即清理」需接受重开无曲目，属产品取舍，未擅自改。
- **Android 8–11 小组件圆角失效**：需 `RemoteViews.setBoolean("setClipToOutline")` 反射实现，但该方法在桌面进程执行，方法名不在白名单会抛 `ActionException` 导致整个挂件「加载失败」。白名单无法验证（本地无 framework sources，googlesource 与 raw.githubusercontent 被网络拦截），故未动。
- **Compose 内约 20 处硬编码中文**：lint 的 `HardcodedText` 只检查 XML。无多语言需求时零行为收益，未做资源化。
