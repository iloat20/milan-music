# 1.0.84（b85）播放页：镜面线下的 34dp 空白带 —— 图层高度漏算了出血

日期：2026-10-27　产物：`dist/milan-music-1.0.84-b85-seamfix-20261027.apk`（2,301,640 B）

## 用户反馈

真机截图（873×1920）：「接缝更大了」。

## 实测（不是猜测）

镜面线在 **y = 951**（封面区横向 std 从 70.19 骤降到 22.50 的那一行）。逐行量横向 std：

| 位置 | 亮度 | 横向 std | 判定 |
|---|---|---|---|
| y=949（镜上 0.9dp） | 134.7 | 70.5 | 正常封面 |
| **y=961 … 1039（镜下 +4.5 … +39.3dp）** | 122~128 | **22.1~22.5** | **均匀空白带** |
| y=1045 起（镜下 +42dp 之后） | 127.1 | 63.2 | 倒影内容回来了 |
| 参考：封面同类区域（y 900~940） | — | 74.1 | — |

- 空白带宽度 = **34.0dp**，与 `CoverRamp`（= 最大模糊半径 34dp）**完全相等**。
- 它不是"倒影被淡掉"：亮度只掉 4~5（122 vs 127），内容却整段消失，std 从 70 掉到 22。

## 根因

第 84 批把 `CoverRamp` 从 0 改成 34dp 出血，同时把 `cascadeAlphas` 的采样区间改成
`[−bleed, bottom]`（= 节点高 557dp），**但图层 Box 的高度还是 `height`（523dp，不含出血）**，
fade 父层也用 `.offset(y = band).height(height)` 贴着镜面线。

`RampLayerContent` 的翻折轴写死在自己的 `y = bandPx` 处（因为出血区在图层内部的前 34dp），
于是「图层顶边 = 镜面线」+「翻折轴 = 镜下 34dp」两件事叠加，整块倒影被下推 34dp：

```
镜下 0 … 34dp   →  图层里 0 … 34dp  →  出血区，RampLayerContent 不画 → 空白
镜下 34dp 起     →  才轮到镜像
```

一句话：**高度有两个来源（`overlayDrawHeight()` 与字面量 `height`），改了一个没改另一个。**

## 改法（`CoverReflection.kt` 三处）

1. **fade 父层覆盖整个节点**：`.offset(y = band).height(height)` → `.height(nodeHeight)`。
   顶边回到外层原点（镜面线以上 34dp）。原来贴镜面线时，DstIn 的矩形会把子图层裁在镜面线以下。
2. **各层 Box 高度 `height` → `nodeHeight`**，与 `RampLayerContent` 的翻折轴对齐。
3. **`fadeAlphas` 增设 `bleed` 参数（默认 `CoverRamp`）**，采样区间改成 `[−bleed, bottom]`，
   与 `cascadeAlphas` 完全同源；降级路径（不画出出血）显式传 `bleed = 0.dp`，否则包络会
   上错 34dp、底部提前淡完。

几何复算（同一套公式，`bleed=34 / bottom=523 / hero=429`）：节点高 557dp，镜面线在节点内
`y = 34dp`；镜下 0dp 取到封面第 429 行（最底行，镜像起点），+16dp → 413，+200dp → 229 ——
逐行退行，没有空档。

`ReflectionLayersTest` 23 → **24 例**，新增
`the fade and the cascade share one sample range`：两条曲线的采样段数必须相同且都等于
`maskSamplesFor(nodeHeight)`、出血顶端 fade 恒 1、镜面线（节点内 `y = CoverRamp`）清晰层恒 1。

| 注入 | 红掉的用例 |
|---|---|
| `fadeAlphas` 采样区间缩回 `bottom`（本次 bug 的数值形态） | 3 例：mask samples…、the fade and the cascade…、sampling the envelope… |
| `cascadeAlphas` 采样区间缩回 `bottom`（与 fade 分叉） | 同上 3 例 |

局限说明：**Box 高度这一条测不了** —— 单元测试拿不到 Compose 布局，它是"两个数字必须相等
却分头写"的问题。本次改动的防护手段是把 `nodeHeight` 作为唯一高度来源（fade 层、各绘制层、
`overlayOnly` 全部读它），并在注释里写清 34dp 空白带的实测数值。
