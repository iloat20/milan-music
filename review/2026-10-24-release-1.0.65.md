# Release 1.0.65 (vc 66, b66)

本包汇总 1.0.64 之后未发布的技术适配、运行时修复与倒影 128dp 调整。
基线：AGP 9.4.1 / Kotlin 2.4.21 / Gradle 9.8.2 / compileSdk 37 / minSdk 26。

## 会话与媒体库（P0）

- 通知/锁屏点击有落点：`MediaSession.setSessionActivity()` 指向 `MainActivity`（singleTop）。
- `PlaybackService` 从 `MediaSessionService` 迁移到 `MediaLibraryService`，真正实现
  `onGetLibraryRoot` / `onGetChildren` / `onGetItem`；曲库树按歌曲/专辑/艺人分页。
- 播放恢复：`onPlaybackResumption()` + `MediaButtonReceiver` + `PlaybackSnapshotStore`。
  快照只存 track id、当前索引和当前曲元数据；恢复窗口为当前项前后各 100 首。
- 队列项改为裸 `mediaId + uri`，由 session 的 `onAddMediaItems` 按索引补元数据；
  新增 `PlaybackTrackIndex`、`LibraryTree`、`LibraryRevision`。
- 富元数据：新增 `ALBUM_ARTIST`（API 30+，缺失回退 `ARTIST`），写入通知/锁屏/Auto。

## 运行时（批次 1）

- R1：API 31+ 不再解码并缓存永不绘制的 512² 翻转封面；每曲少一次
  `softwareCopy + IntArray + createBitmap + 行翻转`，常驻约 −1 MB。
- R2：位图预算统一到 32 分母，五处切片合计 30/32；192 MB 堆下约 22.5 MB，
  留 1.5 MB 解码瞬态余量。
- R7：播放位置快照 5 s → 15 s，DataStore 写盘 720 → 240 次/小时；切歌、暂停、
  服务销毁仍立即写。

## 缺陷修复

- 扫描完整性：`MediaStoreRepository.scanTracks()` 返回 `TrackScan.complete`；
  游标中途失败不再把部分结果发布、写盘并盖 generation。OEM 拒绝 `ALBUM_ARTIST`
  投影时，在读取任何行前回退基础投影。
- 快照写失败隔离：新增 `saveSnapshotSafely`，DataStore 异常只记录 warning，
  不再从 `serviceScope` 逃逸并杀死播放进程；`CancellationException` 继续传播。
- 播放页覆盖首页时，当前曲目行的 60 fps 无限波形停止请求帧；返回首页立即恢复。
- 启动先发布已解码的缓存曲库，再读 MediaStore generation，缩短首屏等待。
