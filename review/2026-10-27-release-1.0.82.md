# 1.0.82（b83）播放页：倒影顶端的清晰层让位从 32dp 收到 16dp

日期：2026-10-27　产物：`dist/milan-music-1.0.82-b83-refltop-20261027.apk`（2,301,640 B）

## 用户反馈

「倒影顶端太清楚」。

## 根因（数值，不是估计）

第 82 批把过渡带整体移到镜面线以下之后，阶梯最内一级是**半径 0 的清晰层**，即
"未经过任何模糊的真实镜像"。它铺了 32dp 才让位完，实测镜下各点的清晰层权重：

| 镜下距离 | 清晰层权重（真实镜像占比） | 累计 blurAt |
|---|---|---|
| 0dp | 1.00 | 0dp |
| 8dp | **0.84** | 3.4dp |
| 16dp | **0.50** | 6.0dp |
| 24dp | **0.16** | 9.3dp |
| 32dp | 0.00 | 12dp |

也就是镜下 16dp 处还有**一半**是原样倒过来的封面底部、24dp 处还有 16%。
封面底部那条深色斜边因此被完整复制了一次，读起来就是"封面底部又被倒过来一份"。

对照图：`review/_top-clear-options-zoom.png`（镜下 0~70dp 放大 3 倍，四档并排）。

## 改法

只有一处几何改动 **加** 一处随之必须改的采样精度：

1. **`BlurRamp` 最内两级提前**（`CoverReflection.kt`）：
   `0dp@0`、`12dp@16`、`24dp@64`、`34dp@160`（原 `12dp@32`、`24dp@80`）。
   清晰层让位距离 32dp → **16dp**，镜下 8dp 处权重落到 0.50、16dp 处归零。
   层数不变（仍是 4 层），不增加任何离屏缓冲。
2. **采样步长 4dp → 2dp**（`MaskStepDp`，上限 200 → 256）。
   最窄一段从 32dp 收窄到 16dp 之后，同样的步长误差按平方翻倍：4dp 下 13dp 处的
   复合不透明度只剩 **0.9755**（门限 0.98），门禁当场红。2dp 下最窄段有 8 段，
   误差回到 0.6% 量级。代价只是每层渐变的 stop 翻倍（`remember` 缓存，不增 GPU 层数）。

## 为什么只动这一个旋钮

- **首级半径必须保持 0**。镜面线两侧清晰度相等是接缝不显形的唯一凭据；把首级改成
  6dp 立刻出现清晰度断崖（红态注入已验：4 例红）。
- **不加层**。每层是一次全屏离屏合成，1080×2400 上 5~10MB。要"更糊"应该调半径，
  不是叠层。
- **不靠收短 `FadeEnd`**。那会同时砍掉倒影的整体长度，而用户指的是顶端清晰度。

## 门禁变化

`ReflectionLayersTest` 21 → **22 例**，改写 3 条、新增 1 条：

| 用例 | 守什么 |
|---|---|
| `the ladder keeps four stops and the mirror line is sharp` | 等效曲线 0/16/64/160，另加 `blurAt(8dp) == 6dp` |
| `the sharp layer must be drawn by the overlay` | 缺清晰层时覆盖率 0 / 0.5（8dp）/ 1（16dp） |
| `the sharp layer hands the top of the reflection over quickly`（新） | 让位距离 ∈ [8dp, 20dp]、镜下 8dp 权重 0.50、16dp 归零、镜面处半径必须 0 |
| `sampling the envelope keeps the composite within two percent` | 2dp 采样后的合成误差 ≤ 2%（4dp 会红） |

**红态验证（三次注入，均已还原）**：

| 注入 | 红掉的用例 |
|---|---|
| `12.dp@16` 改回 `@32`（让位距离长回去） | 3 例：ladder keeps / must be drawn / hands over quickly |
| `MaskStepDp = 4f`（采样退回 4dp） | 1 例：sampling keeps composite within two percent |
| 首级 `radius` 改 6dp（想靠提半径解决） | 4 例：ladder keeps / hands over quickly / mirror line owns a step / ramp climbs strictly |
