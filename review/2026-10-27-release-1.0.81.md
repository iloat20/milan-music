# 1.0.81（b82）播放页：取消封面侧过渡带，倒影改为精确加权平均

日期：2026-10-27　产物：`dist/milan-music-1.0.81-b82-seam-20261027.apk`（2,301,640 B）

## 用户反馈

真机截图（873×1920）：「模糊的地方好像不对，上面的一个条状模糊应该取消」。

## 根因（实测，不是估计）

`BlurRamp` 起点在镜面线**以上** 128dp（第 54~81 批的设计：把过渡带上半压在封面上，
让镜面两侧由同一图层、同一张位图的相邻两行画出）。代价是**封面自己的最后 128dp 被逐级
糊掉**：

| 截图行 | 距镜面线 | 左三分之一区梯度 RMS |
|---|---|---|
| y 440 | −232dp | 7.06 |
| y 600 | −161dp | 4.60 |
| y 820 | −63dp | 2.29 |
| y 960 | 0（镜面线） | 1.80 |

起点 = 960px − 286px(128dp) = y 674。用户在截图里看到的那条横带就是这一段。

## 改法

1. **阶梯起点归零**（`CoverReflection.kt`）：`BlurRamp` = `0dp@0`、`12dp@32`、`24dp@80`、
   `34dp@160`；`CoverRamp` 随之恒为 0。封面从顶到底都是自己的本体，模糊只发生在镜面线以下。
2. **清晰层必须由叠层自己画**（`DrawnLayers = 0..lastIndex`）。以前 `w_0` 那份权重由
   "不透明的封面本体"补上；封面在镜面线结束之后没人补，覆盖率为 `1 − Π(1−w_i)`，
   级联 alpha 有这个性质：`Π(1−a_i) = w_0` —— 也就是**镜面线上直接全透明**、
   16dp 处只补得上一半、32dp 才追平。缺了清晰层就是一条 0~32dp 的色带。
3. **归一化级联**（`cascadeAlpha`）：每层 alpha 取 `w_i / Σ_{j≤i} w_j`，从清晰到糊依次叠加，
   合成结果恒等于**精确的加权平均** `Σ w_i·L_i`，且每一行的 alpha 恒为 1。
4. **fade 提到父层**：逐层乘 `fadeAt` 会把级联 alpha 压到 fade 以下（镜面下方暗一截），
   所以整块倒影外包一层 `fadeAlphas(height)` 的 DstIn。
5. 清晰层不挂 `Modifier.blur`（半径 0 只会白开一层离屏缓冲）。
