### 1.2 双色图标为什么不能再 tint

`ColorFilter.tint` 默认 SRC_IN，会把两半压成同一个颜色，阴阳就退化成单色剪影。所以 `TabIcon` 分出 `Plain` 分支：位图自带颜色、不加 colorFilter，选中态用 `alpha = if (active) 1f else 0.55f` 表达。代价是选中/未选中不再有颜色差异，只剩透明度与 1.08 倍缩放。

### 1.3 图标怎么来的：先去掉那圈描边，再补出互补半

原始 `ic_launcher_foreground.png`（324×324）由两部分组成：实心的半月，以及一圈 r≈154–156 的 1–2px 描边。沿四个方向采样 alpha：

| 半径 | 右 / 下 / 左 三向 alpha | 含义 |
|---|---|---|
| 148–153 | 255 / 255 / **0** | 右下方是实心半，左上是真空 |
| 154–155 | 255 / 255 / **255** | 左上出现细线 → 那就是描边 |
| 157 | 0 / 0 / 0 | 图形外 |

去掉描边（r>153 的 alpha 清零）后，左半变成完全透明，圆形轮廓随之消失——所以单色版只剩一个"逗号"。要恢复圆形，只能用同一张 alpha 掩膜把圆内的互补区域填上另一个颜色：

- `drawable-{mdpi,hdpi,xhdpi,xxhdpi}/ic_tab_taiji.png` = 实心半**墨**、互补半**白**
- `drawable-night-{…}/ic_tab_taiji.png` = 反相（实心半**白**、互补半**墨**），让亮的那半当主角

四个密度分别生成（108/162/216/324），只放一个密度会触发 lint `IconMissingDensityFolder`。

### 1.4 颜色是试出来的，中间方案都被对比度否掉了

| 方案 | 浅色对比度 | 深色对比度 | 结论 |
|---|---|---|---|
| 标准金 `#FFD700` on Paper | **1.27 : 1** | 13.52 : 1 | 否决：浅色小字读不出 |
| 纯白 `#FFFFFF` on Paper | **1.11 : 1** | 18.96 : 1 | 否决：浅色下图标等于消失 |
| 墨色 `#000000` on Paper | **18.97 : 1** | 16.85 : 1（Moonlight） | **采用**（米兰 tab） |
| 收藏红 `#FF3B30` on Paper | **3.20 : 1** | 5.34 : 1 | **采用**（喜欢 tab） |

对比度为 WCAG 2.x 相对亮度公式，页面底色取 Paper `#FAF3E1` / Night `#141009`。

## 2. 切 tab 清空查询

搜索框只属于米兰页，切走时会收起高度；但查询本身原先继续生效，导致回到「喜欢」时列表被残留关键字筛空。`onSelect` 里补 `viewModel.setQuery("")`，切 tab 即清空。

## 3. 稳定性修复

| # | 位置 | 问题 | 处理 |
|---|---|---|---|
| 3.1 | `ArtworkRepository.load` / `loadPlayerArtwork` | 生产者中途取消时给 `await()` 回 `null`，且 `finally` 已把 map 项移除；调用方于是把"滑出合成范围"当成"这首没有封面"，而 `LaunchedEffect` 的 key 没变、不会重试 → 永久占位 | `await()` 得到 null 时回读缓存，再判定有无 |
| 3.2 | `ArtworkRepository` 的 `softwareCopy()` | `copy()` 失败时回退返回 **HARDWARE 位图本身**，后续 `getPixels` 会抛异常并中止协程 | 显式检查并换 software 副本，保证下游读取合法 |
| 3.3 | `MediaStoreRepository` 查询 | 只兜 `SecurityException` 与 `IllegalArgumentException`，而 cursor 跑在远端 provider 上，OEM 还会抛 `SQLiteException`、`DeadObjectException` | 收敛为 `Exception` 并 `Log.w`，空结果交给调用方当作"索引暂不可用"；`VOLUME_*` 常量收进带 `@RequiresApi` 的函数 |
| 3.4 | `HomeScreen` 排序菜单 | 菜单展开时按返回键会退出页面而不是收起菜单 | `BackHandler(enabled = sortMenuOpen) { sortMenuOpen = false }` |
| 3.5 | `values-night/themes.xml` | 基础主题把 `windowBackground` 固定成白色，深色冷启动会先闪一帧白屏，状态栏图标也反色 | 独立夜间主题：`windowBackground #141009`（与 `Color.kt` 的 Night 同值）+ `windowLightStatusBar=false` |

顺带统一了封面圆角比例：列表 52dp 配 10dp、迷你播放器 46dp 配 8.8dp（≈19%）；播放页收藏按钮从 `IconButton` 改成 `noRippleClickable` 的 `Box`，避免按压时在封面上铺出一块圆形底色。

## 5. 已知边界

- **无真机截图**。底部栏的读数、太极在玻璃上的实际辨识度、红色文字在强光下的可读性，均未在设备上确认。
- 浅色主题下太极的**白半与面板底色几乎同亮度**（白 vs 纸 = 1.09:1），圆形靠黑半与边缘亮差读出；深色主题的黑半比玻璃面板略深，同样依赖边缘。
- 喜欢 tab 的红色文字在浅色下 3.20:1，11sp 小字低于 AA 的 4.5:1：图标可辨、文字偏弱。
- 选中态只剩 alpha 0.55 + 1.08 缩放，没有颜色区分。
